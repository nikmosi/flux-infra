# Rust MCP Proxy for Grep.app (`grep-mcp`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, containerize (`FROM scratch`), and deploy a high-performance Rust MCP proxy for `https://mcp.grep.app` with Authelia OAuth 2.0 (RFC 9728) + Static API Token authentication, header normalization (`Accept: text/event-stream`), reachability probe support (`GET /mcp`), and Flux GitOps deployment at `https://mcp-grep.xinfra.ru/mcp`.

**Architecture:** An independent Axum web service exposing `POST /mcp` (Streamable HTTP JSON-RPC 2.0), `GET /.well-known/oauth-protected-resource` (RFC 9728), `GET /healthz`, and `GET /mcp` (returning `200 OK` for reachability checks). Inbound requests are authorized by validating Authelia RS256 JWTs against `https://auth.xinfra.ru/jwks.json` or matching a static API token via constant-time comparison. Upstream calls to `https://mcp.grep.app` are executed with `Accept: application/json, text/event-stream`. The binary is compiled statically against musl libc, packaged in `scratch` containers with root CA certificates, built in CI, and deployed via Flux.

**Tech Stack:** Rust 1.95+ / 1.99.1 (musl target), Axum 0.8 / Tokio, Serde / Serde_json, Reqwest (rustls), Jsonwebtoken, Subtle, Docker multi-stage (`scratch`), Forgejo Actions, Flux CD (HelmRelease / IngressRoute), Authelia OIDC.

**Spec:** [docs/superpowers/specs/2026-10-18-grep-mcp-design.md](file:///home/nik/git-repos/flux/docs/superpowers/specs/2026-10-18-grep-mcp-design.md)

## Global Constraints
- Compiler: Rust 1.99.1 (Docker build) / Rust 1.95+ (musl target).
- Final Container Image: `FROM scratch`, containing only the static binary, `/etc/ssl/certs/ca-certificates.crt`, and `/etc/passwd` for UID 65532:65532.
- MCP Transport: HTTP `POST /mcp` adhering to JSON-RPC 2.0 and MCP protocol specification.
- Discovery: `GET /.well-known/oauth-protected-resource` returning RFC 9728 metadata for Authelia.
- Token Validation: Authelia RS256 JWT validation checking `iss`, `aud`, `exp`, and `kid` via `https://auth.xinfra.ru/jwks.json`, or fallback constant-time comparison against `STATIC_API_KEY`.
- Probe Support: `GET /mcp` must return HTTP `200 OK` with JSON description to satisfy Google Gemini Spark reachability check.
- Header Normalization: Requests to `https://mcp.grep.app` must include `Accept: application/json, text/event-stream`.
- No Direct Main Push to Flux: Use valid git commits with `--no-verify`.

## Review Focus
- Unauthenticated requests to `POST /mcp` must return HTTP 401 with `WWW-Authenticate: Bearer resource_metadata="..."`.
- `GET /mcp` must return HTTP 200 OK without requiring authentication.
- Static API key comparison must be constant-time to avoid timing side-channels (`subtle::ConstantTimeEq`).
- Upstream HTTP errors or network timeouts from `mcp.grep.app` must not panic the server; they must return JSON-RPC responses with `isError: true`.
- Statically linked musl binary must bundle `/etc/ssl/certs/ca-certificates.crt` so outbound HTTPS requests succeed in `scratch`.
